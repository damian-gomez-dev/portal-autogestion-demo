# 🌐 Portal de Autogestión en Discapacidad (Demo Institucional)

Plataforma web modular diseñada para optimizar y despapelar el circuito de gestión, presentación de planillas y auditoría de prestaciones por discapacidad (Ley 24.901) en Agentes del Seguro de Salud y Obras Sociales.

---

### 🎯 Propósito del Proyecto
Este desarrollo forma parte de las soluciones tecnológicas orientadas a resolver los cuellos de botella operativos más comunes en el sector de salud:
* **Fricción en la recepción de documentación:** Canales descentralizados que saturan los e-mails institucionales.
* **Falta de autogestión para prestadores:** Demoras en la consulta de estados de facturación y acceso a instructivos.
* **Carga manual ineficiente:** Procesos analógicos propensos a errores humanos y costos operativos elevados.

---

### ✨ Características Principales
* 📱 **Diseño Responsivo e Institucional:** Interfaz limpia, accesible y adaptada para equipos de escritorio y dispositivos móviles.
* 📂 **Centro de Descargas Estructurado:** Acceso rápido a normativas, instructivos y planillas oficiales organizadas por módulos prestacionales (Rehabilitación, Transporte, Escolaridad, CET, etc.).
* 📥 **Ventanilla Digital Integrada:** Enlaces directos a formularios dinámicos para la presentación de legajos y consultas de facturación.
* 🧭 **Navegación Fluida por Pestañas (SPA):** Experiencia de usuario optimizada mediante vistas dinámicas sin recargas innecesarias.

---

### 🛠️ Stack Tecnológico
* **Frontend:** HTML5, CSS3 (Variables CSS, Flexbox/Grid), JavaScript vainilla (Vanilla JS).
* **Iconografía / Estética:** Diseño minimalista inspirado en interfaces corporativas de alta usabilidad en salud.
